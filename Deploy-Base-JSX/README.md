# Mole Motors – codice del progetto

Qui ci sono backend (`be/`), frontend (`fe/`) e script di avvio. Il `render.yaml` per il deploy sta nella radice della repo.

La documentazione completa (avvio, **accessi e credenziali di prova**, schermate, sicurezza, deploy su Render)
è nel [README principale](../README.md).

Avvio rapido:

```bash
createdb -U postgres salone_auto
./avvia.sh        # Windows: avvia.cmd
```
